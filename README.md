# 🤖 AI Interview Agent

An AI-powered technical interviewer that conducts personalized, multi-turn interviews based on a candidate's learning journey. The system adapts questions dynamically, asks intelligent follow-ups, maintains conversation context, and provides detailed feedback at the end of the interview.

---

## 🚀 Features

- 🎯 Personalized technical interviews
- 🧠 AI-generated follow-up questions
- 💬 Multi-turn conversation
- 📚 Curriculum-aware questioning
- 📊 Performance evaluation & feedback
- 📈 Progress tracking
- 📱 Responsive modern UI

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/your-username/AI-Interview-Agent.git
```

Go to the project

```bash
cd AI-Interview-Agent
```

Install dependencies

```bash
npm install
```

Run the frontend

```bash
cd frontend
npm run dev
```

Run the backend

```bash
cd backend
npm run dev
```

---

## 🌐 Environment Variables

Create a `.env` file in the backend.

```env
OPENAI_API_KEY=
MONGODB_URI=
PINECONE_API_KEY=
```
